# KINGINAZOO 👑🐾

A Streamlit prototype for a multi-animal guessing game.

## Features

- Prominent KINGINAZOO branding
- Virtual coin balance
- Bet options: 1, 10, 100, 1,000
- Multiple animals can be selected in one round
- Animal multipliers
- Flashing/randomized reveal animation before the final winner
- Payout calculation
- Round history

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub / Streamlit Cloud

Push this project to GitHub using the `main` branch and deploy `app.py` with Streamlit Community Cloud.
